M.S.5 STATIC ROOM TEMPLATE ASSETS

Put room-owned static assets here when they are not intentionally shared elsewhere.
Suggested names:
  room.webp / room.png   Main room image
  portrait-*.webp        Optional room-specific portraits
  object-*.webp          Optional overlay art

For an ordinary static scene, set ROOM_CONFIG.image in ../index.html to:
  assets/room.webp

Do not duplicate a large asset if it is intentionally shared with another system.
